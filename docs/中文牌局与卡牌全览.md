## 先看全局盘面

先选牌局与关系模式，再选精选或整盒，最后进入某个阶段；系统只会从这个阶段的候选卡中出题。亲密插件和深卡另有同意条件。

| 牌局 | 适合谁 | 建议节奏 | 精选／整盒可选量 | 默认路线 |
|-|-|-|-|-|
| 初识局 | 4–10人，陌生或半熟 | 45–60分钟；一晚10–13张 | 26／38张 | 认识一下 → 破冰 → 展开 → 收尾 |
| 朋友局 | 3–8人，熟悉的朋友 | 60–90分钟；一晚12–18张 | 主流程44／61张；插件另10／16张 | 直接开聊 → 说点真话 →［亲密插件］→ 故事与未来 →［加码］→ 收尾 |
| 知己局 | 2–4个最信任的人 | 60–90分钟；一晚9–10张 | 22／43张 | 看见近况 → 讲述与暗房 → 把话带出去 → 终局 → 无卡收尾 |
| 心动局·暧昧版 | 2人，互有好感、未确认关系 | 30–45分钟；一局6–10张 | 29／52张，含可选亲密 | 轻松聊聊 → 慢慢靠近 →［聊点心动］→ 留下一句 |
| 心动局·恋人版 | 2人，已经交往 | 45–75分钟；一局6–10张 | 32／45张，含可选亲密 | 恋爱日常 → 更懂彼此 →［亲密开麦］→ 留下一句 |
| 独处局 | 1人，按天写日记 | 每天10–15分钟；天气＋主卡 | 随便抽一张可用161张；每日主卡另按星期和周次过滤 | 天气 → 当天主卡 →［周日天气图］→ 今天发现的自己 |

方括号表示可选环节。默认路线不是强制顺序：可以点阶段标签直接跳转，也可以提前结束；需要同意的阶段仍须确认。人数是玩法建议，不是按人数自动更换题库的开关。

当前题库共230张，其中218张至少有一种实际出牌入口，12张只保留在题库、当前所有玩法均不出。后文逐阶段列出候选卡，最后按12个系列给出全部230张中文原题及出现位置。精选里的卡在整盒也存在；“仅整盒新增”表示精选不会出现。牌池张数是备选量，不是一晚必须抽完的数量。

## 出牌判断与例外

| 情况 | 实际怎样出牌 |
|-|-|
| 选“精选” | 只使用该阶段的精选名单。 |
| 选“整盒” | 使用同一阶段的精选名单＋仅整盒新增名单；不会从全库230张随便抽。 |
| 随机阶段长按一张牌 | 按住的卡背原地发光、飞出；题面仍由系统在当前候选池随机决定，优先同一场景以前没抽过的题。按的位置不锁定一道特定题。 |
| 选择阶段点一张牌 | 按所点卡的真实题目出牌。已抽过的题在有新题可选时会暂时不可选；未见题用尽后才回到已见题。 |
| 同一局再次进入已玩阶段 | 保持原来的排布、空位和已抽进度；已经抽走的同一卡在这一局的其他阶段也不再重复抽出。 |
| 再开一局 | 重新排列、清空当局空位和当局抽取状态；跨局已见记录仍保留，并继续优先出未见题。 |
| 低于4星或4辣 | 不触发逐卡深卡确认；若所在阶段本身需要同意，仍先过阶段确认。 |
| 4星、5星、4辣、5辣 | 先显示等级与同意询问，题目不提前露出；同意后才翻开。阶段同意和逐卡同意互相独立。 |
| 深卡选“放回，换一张” | 不计已抽张数，不消费“过”；原位置留空。随机阶段有替代卡则自动换，选择阶段由原人重新点选。 |
| 姓名模式点“过” | 每人每局最多2次。有替代题的随机/选择阶段，卡回到原位，同一人换题；系统会尽量避免立刻再抽这张。 |
| 没有替代题时点“过” | 只跳过当前人的回答；卡仍保留给需要回答的其他人。匿名模式不按人限制“过”的次数。 |
| 进入朋友局亲密插件 | 先在设置中启用并全员同意，才把该段插到“说点真话”之后；进入该段还会确认，4/5辣翻牌再逐张确认。 |
| 进入其他需同意阶段 | 朋友加码；知己“把话带出去”和“终局”；心动两版的可选亲密阶段。不同意就跳过。 |
| 线上、投屏、计时或语言变化 | 改变提示、呈现或计时，不另换阶段牌池。没有根据聊天回答、现场情绪或人数动态推荐新题的功能。 |

当前新版的多人阶段只有随机、点选和不抽卡三种；旧版“体检按清单顺序抽”的规则已经不适用于本版。卡名含“深”不等于一定4星：例如三观深02是2星、三观深04是3星，是否确认要看实际星／辣等级。

真正的硬上限只有四处：初识“认识一下”1张、初识“收尾”1张、朋友“收尾”1张、知己“终局”2张。其余阶段没有设置硬性抽牌上限，建议数量用于控制节奏。心动局所有阶段均无硬上限。

“所有人都答”的卡由全体回答；填写名字后系统逐人轮转。心动局每张两个人都答，轮流先回答。匿名模式不跟踪每个人的完成顺序，需要现场自行轮流。三观题按题型同时亮态度，少数派先说；滑杆题伸0–3根手指，线上改为同时在聊天框发0–3。

历史优先按牌局记忆：心动两种模式共用心动局的已见记录；不同牌局没有跨场景统一去重。同一阶段候选都已见过时会允许重用，不会因此永久抽不到卡。

## 初识局的阶段与卡池

**适用情况：**陌生或半熟的人，线上线下都可以：新同事、社群活动、朋友的朋友

**玩法节奏：**先认识一下，再直接破冰，不单独聊天气；主流程建议抽 10–13 张：认识一下 1 张、破冰 3–4 张、展开 5–7 张、收尾 1 张；可以按现场节奏点击阶段标签跳转；不必把一个阶段抽完；认识一下和收尾所有人都答，其余轮流抽

**这个牌局不安排：**暗房显影：留给更熟悉的人；亲密开麦、恋爱体检：这个场景不加入；钱包开麦：本轮初识牌池不安排钱题；生命列车里涉及生死、葬礼的题：不放入初识牌池

## 朋友局的阶段与卡池

**适用情况：**熟悉的朋友聚会

**玩法节奏：**把开场、热场和互看合为直接开聊，不单独聊天气；主流程建议抽 12–18 张：直接开聊 2–3 张、说点真话 3–4 张、故事与未来 6–10 张、收尾 1 张；可选加码或亲密插件占用同一晚的抽牌预算，加入后相应少抽前面阶段，不额外堆时长；可以按现场节奏点击阶段标签跳转；加码和亲密插件全员同意才进入；四星卡、四辣和五辣卡，翻开前仍需单卡同意

**这个牌局不安排：**主流程不放五星卡：留给知己局；恋爱体检：不放入朋友牌池；高阶暗房和高阶钱包题：主要留给知己局；亲密题只在全员同意启用插件后出现，不要求关系中的另一人在场

## 知己局的阶段与卡池

**适用情况：**2–4 个最信任的人，适合深夜

**玩法节奏：**开场和镜子合成“看见近况”，不必先轮流报天气；所有阶段都可以按大家的意愿跳转。；建议一晚共抽 9–10 张：看见近况 2 张、讲述与暗房 5 张、行动 1 张、终局 1–2 张。卡池有余量，不必抽完。；四星及以上仍逐卡确认；行动、终局需要全员同意才进入。终局最多抽 2 张，所有人都答。；最后不抽卡：每人说一句“今晚我想记住的一句话”。
