# 对话卡牌 · 网页抽牌游戏

这是一套用来认识自己、朋友聚会和暧昧/恋人聊天的对话卡牌的网页版。打开网页后选一个场景，按阶段抽牌、翻牌，然后大家围绕卡上的问题聊天。

## 目录

```
talk-cards/
├── CODEX_PROMPT.md      给 Codex 的完整需求
├── AGENTS.md            Codex 每次都会读的项目规则
├── README.md            本文件
├── data/
│   ├── cards.json       230 张卡（中英文、系列、级别）
│   ├── series.json      12 个系列（名字、颜色、卡背图案关键词）
│   ├── scenes.json      5 个场景（阶段、牌池、规则、提示语）
│   └── game-data.js     由上面三个文件自动生成，网页只读这个文件
└── tools/
    └── build_data.py    检查数据并重新生成 game-data.js
```

网页本身由 `index.html`、`styles.css`、`app.js` 和 `js/` 下的规则、卡背及动画脚本组成。`table-fx.css` 与 `js/table-fx.js` 负责桌面的洗牌、码牌、飞牌、翻牌、收牌动画，不改变抽牌规则。

## 用 AI 继续研究和维护

1. 在 Codex 里打开这个文件夹，或者在终端里 `cd` 到这个文件夹，再启动 Codex。
2. 把下面这段话发给它：

   > 请先阅读 AGENTS.md、README.md 和 CODEX_PROMPT.md，再读 data/ 下的数据文件，然后先核对当前实现与我本轮授权，再做指定修改。完成后按第九节自检，并用中文汇报。

## 怎么玩

- **线下：** 双击 `index.html` 打开网页，把手机或平板放在桌上轮流抽。
- **线上：** 主持人打开网页，在视频会议里共享屏幕。
- **牌桌：** 第一次进入阶段时随机排列一次，不显示数字牌号。本局里排列保持不变，抽走的位置留下淡虚线空位，其他卡不补位；离开阶段再回来也保留。再开一局时重新排列。卡多时全部放在一条可左右滑动的牌轮里，少量卡保留居中扇面。
- **抽牌：** 按住一张卡背约 0.8 秒，会先高亮选中；松手后这张卡原地发光，再从原位置飞到中央翻开。滑动不会误抽牌，空位上长按会取最近的卡。电脑可用滚轮、拖动、两侧箭头或方向键查看；长按空格抽可视区中央附近的卡。选牌阶段直接点卡背，优先选以前没抽过的，其余卡暂时变灰，轮到它们时从原位置恢复可选。随机题目仍优先选择以前没抽过的，顺序题仍按顺序；卡背位置不改变这些规则。深卡先征得同意才翻开，回答计时器在翻稳后才出现。
- **收尾：** 结束时先收卡，再让全屏背景变亮，最后显示回顾。系统开启减少动态效果时改用淡入，牌轮仍可滑动、空位仍保留。
- **过牌：** 有名字的玩家每局可“过”两次。随机阶段有替代卡时由同一个人换牌；选牌阶段重新选。固定卡、顺序抽或没有替代卡时直接换人，题目和已抽进度保留。没填名字时不计次数，跳过固定卡、顺序卡或最后一张卡后提示“这张先跳过了”。
- **独处：** 翻开今天的卡，写下的文字自动保存在本机。完成后，已翻开的卡先缩到上方，再让全屏背景暖亮，依次出现收尾语和导出、回看、首页按钮；系统开启减少动态效果时仅淡入。回看今天可继续写，导出日记可保存为文字文件。
- **想把链接发给别人：** 把整个文件夹上传到任意一个静态网页托管服务（比如 GitHub Pages、Netlify），不需要服务器。

## 修改卡牌内容

1. 只有得到明确的数据修改授权后，才用文本编辑器修改 `data/cards.json`；如果要改场景或系列，就修改 `scenes.json` 或 `series.json`。
2. 在这个文件夹里运行 `python3 tools/build_data.py`。它会先检查数据，没有问题才会生成新的 `game-data.js`。
3. 刷新网页。

## V2：压缩流程与卡组重规划

原版完整保留，此目录为2026-10-16新版本。230张题目、12个系列、引擎与交互不变；只调整多人场景配置。伙伴场景内部ID仍为partners，界面改名心动局；daily显示暧昧版，night显示恋人版。

| 场景/模式 | 阶段顺序 | 主阶段数 | 一晚建议抽数 | 预计时长 |
| --- | --- | --- | --- | --- |
| 初识局·标准 | 认识一下 → 破冰 → 展开 → 收尾 | 4 | 10–13 | 45–60 分钟 |
| 朋友局·标准 | 直接开聊 → 说点真话 → 故事与未来 → 加码（可选） → 收尾 | 4 | 12–18 | 60–90 分钟 |
| 知己局·标准 | 看见近况 → 讲述与暗房 → 把话带出去 → 终局 → 收尾 | 5 | 9–10 | 60–90 分钟 |
| 心动局·暧昧版 | 轻松聊聊 → 慢慢靠近 → 聊点心动（可选） → 留下一句 | 3 | 6–10 | 暧昧版 30–45 分钟／恋人版 45–75 分钟 |
| 心动局·恋人版 | 恋爱日常 → 更懂彼此 → 亲密开麦（可选） → 留下一句 | 3 | 6–10 | 暧昧版 30–45 分钟／恋人版 45–75 分钟 |

建议抽数按一晚合计，可选阶段计入预算；可以少抽或跳阶段，深卡与同意门控不变。初识认识仪式及多人收尾限1张，知己终局限2张，其余不硬限，心动局所有阶段不限。

## 两种卡组

- **精选：** 每个可抽阶段至少备有建议抽数两倍的卡，留给过和深卡放回；不是要求抽完整池。
- **整盒：** 同一流程的更多备选卡，适合反复玩；不沿用旧每级/每系列12张及亲密19/12的口径。
- **朋友亲密插件：** 精选10/整盒16，含四辣五辣，聊个人经历/想法，不用在场伴侣；进入需全员同意，四辣以上还需单卡确认。

## 编号对照

网页代码里用英文 id 标识每张卡，比如 `mirror-d10`；卡面上显示中文编号，比如“镜像深10”，和 Excel 手册里的编号一致。id 里带 `d` 的是深度版。

## 隐私

网页不联网，也不上传任何内容。所有记录只保存在当前浏览器里。

## 三观题与版本存储

三观题保留在朋友“说点真话”（精选2/整盒3）和知己“讲述与暗房”（精选2/整盒3），沿用同时亮态度；初识不放三观，线上提示也移除此项。心动暧昧亲密实际可选1–3辣，恋人可选3–5辣，仍要同意。原版文件保存不变不代表浏览器记录隔离，请勿据此假定两版本分别保存日记。
